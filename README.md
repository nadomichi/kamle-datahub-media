# Kamle District Data Hub - media files

Public photos, brochures and blank forms used by the Data Hub chatbot (WhatsApp / Telegram) and the forms portal.
Each file is published automatically at: https://<this-site>.vercel.app/<district>/<folder>/<file-name>

| Folder | Used by (sheet tab > column) |
|---|---|
| kamle/forms/ | Blank application forms as PDF (PRC, ST, income, ID card...). Used by SERVICES > link and by the forms portal. |
| kamle/tourism/ | Photos / brochures for TOURIST_PLACES > image_link. |
| kamle/accommodation/ | Photos / tariff cards for ACCOMMODATION > image_link. |
| kamle/travel/ | Photos / posters for TRAVEL_SERVICES > image_link. |
| kamle/health/ | Photos for HEALTH_FACILITIES > image_link. |
| kamle/schools/ | Photos for SCHOOLS > image_link. |
| kamle/banks/ | Photos for BANKS_CSC > image_link. |
| kamle/fair-price-shops/ | Photos for FAIR_PRICE_SHOPS > image_link. |
| kamle/utilities/ | Photos for UTILITY_OFFICES > image_link. |

Rules: JPG/PNG under 1 MB, PDF under 2 MB; lower-case names with hyphens; never rename or delete a file in use; replace by uploading with the same name.
Everything in this repository is public: never upload filled forms, ID documents or personal data.
